# RiskApp v0.1.0

RiskApp `v0.1.0` is the first tagged development release of the offline-first risk and opportunity manager.

## Highlights

- Native PySide6 desktop client backed by a local SQLite cache.
- FastAPI service with project roles, audit history, snapshots, and CSV export.
- Automatic background synchronization with backoff and per-project isolation.
- Durable outbox, idempotent server receipts, monotonic change cursors, explicit conflict resolution, and field-level merging.
- Password and token hardening, bounded HTTP bodies, safe spreadsheet exports, and synchronized REST/sync authorization rules.
- Reproducible Python 3.14 tooling with package-wide mypy, Ruff, migration drift checks, coverage gates, container validation, and Trivy scanning.

## Verification

The release candidate passes 391 automated tests with 90.18% combined coverage, 92.83% line coverage, and 80.23% branch coverage. Mypy checks 129 application modules, and the canonical lint, migration, compilation, and dependency-integrity checks pass.

## Running the release

Follow the [setup guide](../SETUP_GUIDE.md), then start the API and desktop client in separate terminals:

```bash
bash scripts/run_server_dev.sh
bash scripts/run_client_dev.sh
```

The development credentials documented in the repository are for local demonstration only.

## Known limits

- The Docker workflow packages the API; the desktop client runs natively on the host.
- SQLite is the fully exercised persistence path. Production PostgreSQL CI, deployment automation, backup/restore validation, and encryption operations remain outside this release.
- Production password-reset delivery is not included.
- This is a `0.1` development release and does not promise backward compatibility with future minor releases.
